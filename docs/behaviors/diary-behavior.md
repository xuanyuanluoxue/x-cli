# x diary P0 行为规格

> **目标读者**：接续开发的 AI agent / 维护者
>
> **范围**：`x diary "内容"` 与 `x diary list [--limit N]`
>
> **对应测试**：`tests/test_diary.py`
>
> **状态**：P0

---

## 1. 存储约定

### 1.1 路径

日记使用 x-cli 自己的本地数据目录，不读写 Xavier、Obsidian 或其他日记系统。

| 平台 | 默认目录 |
|---|---|
| Windows | `%LOCALAPPDATA%\x-cli\diary\` |
| macOS / Linux | `$XDG_DATA_HOME/x-cli/diary/`，未设置时为 `~/.local/share/x-cli/diary/` |

- 环境变量 `XCLI_DIARY_DIR` 可覆盖整个日记目录，主要用于测试和用户自定义。
- 每个有内容的自然日对应一个 UTF-8 Markdown 文件：`YYYY-MM-DD.md`。
- 日记目录在首次解析路径或首次写入时自动创建。

### 1.2 Markdown 格式

首次写入 `2026-07-17` 的文件格式如下：

```markdown
# 2026-07-17

- 14:30 今天开始开发 x diary
```

- 时间使用本机当前时区的 24 小时制 `HH:MM`。
- 同一天再次写入时，在原文件末尾追加新条目，不覆盖已有内容。
- 多行内容的后续行缩进两个空格，保持在同一个 Markdown 列表项内。
- 写入后文件以一个换行符结尾。

## 2. 命令行为

### 场景 1：写入当天日记

**Given**：今天是 `2026-07-17`，当前时间为 `14:30`，当天文件不存在。

**When**：执行 `x diary "今天开始开发 x diary"`。

**Then**：

- 退出码为 `0`。
- 创建 `2026-07-17.md`，内容符合第 1.2 节格式。
- stdout 输出 `✅ 日记已写入：2026-07-17`。

### 场景 2：同一天追加

**Given**：`2026-07-17.md` 已有一条日记。

**When**：当天再次执行 `x diary "第二条内容"`。

**Then**：

- 退出码为 `0`。
- 原条目保持不变，新条目追加到文件末尾。
- 日期标题只出现一次。

### 场景 3：拒绝空内容

**When**：执行 `x diary ""` 或内容只含空白字符。

**Then**：

- 退出码为 `2`。
- stderr 输出 `❌ 日记内容不能为空`。
- 不创建当天文件。

### 场景 4：默认列出最近 7 个有日记的日期

**Given**：日记目录存在 9 个合法日期文件，日期不连续。

**When**：执行 `x diary list`。

**Then**：

- 退出码为 `0`。
- stdout 第一行是 `最近 7 个日记日期：`。
- 后续每行输出一个 `YYYY-MM-DD`，按日期从新到旧排序。
- 只输出最近 7 个有日记文件的日期，不补齐没有日记的自然日。

### 场景 5：自定义列出数量

**Given**：日记目录存在至少 3 个合法日期文件。

**When**：执行 `x diary list --limit 3`。

**Then**：只按从新到旧顺序输出最近 3 个日期，退出码为 `0`。

### 场景 6：空日记库

**Given**：日记目录为空或只有不符合 `YYYY-MM-DD.md` 的文件。

**When**：执行 `x diary list`。

**Then**：

- 退出码为 `0`。
- stdout 只输出 `📭 暂无日记`。

### 场景 7：非法 `--limit`

**When**：`--limit` 是 `0`、负数或非整数。

**Then**：

- argparse 拒绝参数并返回退出码 `2`。
- 不读取或修改任何日记文件。

### 场景 8：帮助与入口派发

**When**：执行 `x diary --help`。

**Then**：

- 退出码为 `0`。
- stdout 包含 `usage: x diary`、写入用法、`list` 和 `--limit` 说明。
- 顶层 `x --help` 的子命令提示包含 `diary`。

---

## 3. 列表识别规则

- 只有文件名能严格解析为真实日期的 `YYYY-MM-DD.md` 普通文件才是日记文件。
- `2026-02-30.md`、`notes.md`、目录名 `2026-07-17.md/` 均忽略。
- P0 的 `list` 只列日期，不读取或预览日记正文。

---

## 4. P0 不做

- 不按指定日期写入或补写。
- 不编辑、删除、搜索或同步日记。
- 不连接 Obsidian、云端或 Xavier 共享日记。
- 不增加第三方依赖。
